# Asthme Aigu Grave 
#AAG #Urgences #EDN

Asthme aigu grave = urgence vitale.

Signes de gravité :
- Dyspnée sévère, parle difficilement
- FR > 30/min
- SpO₂ < 90 %
- Silence auscultatoire
- Tirage, muscles accessoires
- ATCD de réanimation pour asthme

Prise en charge immédiate :
- Oxygène haute concentration (objectif SpO₂ ≥ 94 %)
- [[Salbutamol]] nébulisé sous O₂ (répété ou continu)
- [[Ipratropium]] bromure nébulisé associé
- Corticoïdes systémiques immédiats (IV ou PO)

Si échec :
- Sulfate de magnésium IV 2 g
- Gaz du sang artériel
- Appel réanimateur / anesthésiste

Gaz du sang :
- Hypocapnie = encore ventilant
- Normocapnie = fatigue respiratoire
- Hypercapnie = pré-arrêt respiratoire

Intubation :
- Dernier recours
- Très à risque
- Bronches fermées → piégeage de l’air
- Hyperinflation dynamique → hypotension, pneumothorax, arrêt cardiaque

Pièges :
- Inhalateur seul
- Oublier les corticoïdes
- Donner des sédatifs
- Attendre les examens
- Confondre bradypnée et amélioration
